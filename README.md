Trabalho prático elaborado por Vinicius Correa Kock para a disciplina de Teoria da Computação (TEC0001), ministrada pela professora Karina Girardi Roggia, na Universidade do Estado de Santa Catarina (UDESC).

Para executar, é necessário ter o Python instalado na máquina, e nenhuma
outra biblioteca ou dependência externa é necessária. Para executar o
código, basta baixar no repositório do GitHub ou através do arquivo
compactado no moodle e extraí-lo em alguma pasta.

No mesmo diretório, tenha:
i) O script Python: main.py realizado nesse trabalho.
ii) O arquivo de entrada, para os testes, com a extensão .in

Comandos de execução:
i) python3 main.py [nome_do_arquivo_de_entrada1.in, nome_do_arquivo_de_entrada2.in……]
ii) Por exemplo: Com um arquivo -> python3 main.py teste.in ; 
Com múltiplos arquivos -> python3 main.py teste1.in teste2.in ...

Observação
a) Se nenhum arquivo de entrada for especificado, o programa vai executar todos os arquivos com a extensão .in no diretório atual; 
b) Não é necessário criar ou utilizar um ambiente virtual Python para executar o código.

Para testar a simulação, execute a máquina de entrada (.in) e a máquina de
saída (.out) no simulador utilizado na disciplina:
https://morphett.info/turing/turing.html. As duas máquinas, devem retornar
o mesmo resultado para uma determinada entrada.
